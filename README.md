# Gabby releases

Hold-to-talk dictation for macOS that runs entirely on your Mac.

Download the latest `Gabby-<version>.zip` from [Releases](../../releases/latest), unzip it, and drag
Gabby into Applications. It's signed and notarized, and updates itself from here.

`appcast.xml` is Gabby's update feed (Sparkle). Every update is signed; installed copies refuse
anything that isn't.
